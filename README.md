# 拍一拍点名助手

一个纯本地运行的中文网页，用来清点人名单：上传微信里「XXX 拍了拍我」的截图，自动识别谁拍了、谁还没拍。

## 名单可以自己改

页面顶部有「**名单设置**」，展开后把名字改成自己需要的名单（每行一个名字），点「保存名单」即可。名单会记住在本浏览器里，下次打开还在。适合分享给别人用。

## 怎么用

1. 双击打开 `index.html`（推荐用 Chrome / Edge 浏览器）。
2. 把微信截图拖进去（支持多张，可反复添加）。
3. 点 **「开始识别」**。
4. 页面会自动：
   - 用 OCR 读出截图里的文字；
   - 找出「XX 拍了拍我」里的名字；
   - 和内置的 28 人名单比对；
   - 分成 **已拍 / 未拍** 两栏显示。
5. 结果可以 **点击名字手动修正**（识别错了点一下即可切换）。
6. 用 **「复制名单」** 把未拍名单复制出去。

## 注意事项

- **图片只在本地浏览器里识别，不会上传到任何服务器。**
- 首次识别需要联网下载：
  - OCR 引擎（约几百 KB）；
  - 中文识别模型（标准版约 20MB，快速版约 1.7MB）。
  - 下载一次后会缓存，之后基本不用再下。
- 识别精度可在右上角切换：
  - **标准**：更准，但模型大、首次下载慢；
  - **快速**：更快，模型小，但个别生僻字/模糊截图可能识别偏差。
- 微信截图里的「拍一拍」格式应为：`"某某" 拍了拍我`（或 `某某 拍了拍我`）。若截图是别人视角的「拍了拍你」，识别可能不准，建议以自己视角截图。
- 名字旁出现 **橙色 `!`** 表示：截图里出现了这个名字，但没识别到它对应的「拍了拍」——可能是对方只是在聊天里出现、或 OCR 漏了「拍了拍」，请人工核对一下。

## 人名单（28 人）

默认名单内置在页面代码里（`DEFAULT_ROSTER`）。也可以在页面上的「名单设置」里直接改，无需动代码。

## 部署到网上分享给别人

这是一个纯静态单文件网页，可以部署到任意静态托管：

- **Netlify Drop（推荐，无需注册）**：打开 <https://app.netlify.com/drop>，把整个 `paiyipai` 文件夹拖进去，立刻得到一个公开网址。
- **GitHub Pages（网址长期稳定）**：新建仓库 → 上传这两个文件 → Settings → Pages 开启即可。
- **直接发文件**：把 `index.html` 发给对方，双击即可打开（最简单，但不是网址）。
